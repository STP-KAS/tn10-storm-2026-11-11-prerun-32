# Method

The runner is pre-run 25's, with two changes named before the arm. The family table is floor 1–12 and the KCC-20 launch as family 13. The Mini gate accepts the not-reachable file in [MINI-NOT-REACHABLE.md](MINI-NOT-REACHABLE.md) and does not require an armed file we cannot honestly write.

A hop is one transaction. The mint line is the launch family, one mint at a time. A guest carrier counts only when the id the kit logged is among the desk node's accepted ids. The template reader is the desk node's own template, read-only, every 3 s.

The steps are the same length on purpose. Nothing changes between BASE and RETURN except the clock. The family count is not changed mid-run.
